# 2026-09-07 작업 종료 및 재개 안내

## 오늘의 종료 상태

AI-DLC 2.7.1 공식 Codex 배포 파일에 프로젝트 규칙을 추가하고,
공식 `aidlc-init` 절차로 `260907-local-agent` 작업을 생성했다.
기존 코드는 Brownfield 기준선이며 AI-DLC 승인·검증을 소급하여 완료 처리하지 않았다.

- 범위: classic / Standard. 초기화 3단계 완료, 전체 26단계 중 3단계 완료.
- 저장 위치: `aidlc/spaces/default/intents/260907-local-agent/`.
- 오늘 종료 요청에 따라 공식 `aidlc-orchestrate.ts park`로 일시 정지했다.
- 재개 위치: reverse-engineering. 표시되는 Running 상태와 별개로 Runtime State의 Parked 필드가 재개를 제어한다.
- `practices-discovery`의 팀 관행 승인과 제품 설계·검증 단계는 아직 수행하지 않았다.
- 프로젝트 규칙은 현재까지 사용자와 확정한 선택을 기록한 설정이며, `PRACTICES_AFFIRMED` 기록을 임의로 만들지 않았다.

doctor의 runtime-graph-missing 및 초기화 단계 Untracked 표시는 후속 단계 검증에서 확인할 진단 항목이다.
현재 대화는 상위 projects 폴더에서 시작했으므로 하위 프로젝트 설정의 자동 적용 근거로 삼지 않는다.

## 확정된 제품 요구사항

- Next.js 프론트 / FastAPI 백엔드 / LM Studio 로컬 모델 구성.
- 기본 모델 openai/gpt-oss-20b, 모델 목록 선택 UI, 연결 상태 로그.
- Enter 전송, Shift+Enter 줄바꿈.
- 검색 엔진·질의·결과 개수 표시 및 출처 링크 제공.
- T1 롤 질문은 e스포츠 팀으로 해석하며 근거 없는 경기 결과는 생성하지 않는다.

## 남아 있는 실제 제품 문제

1. T1 최신 5경기 결과는 아직 정확히 제공하지 못한다. 검색 결과를 찾았다는 것과 경기 정보를 검증했다는 것은 다르다.
2. 검색 과정은 현재 최종 응답 후 표시된다. 검색 중 실시간 진행 표시가 필요하면 스트리밍 또는 단계 이벤트 API가 필요하다.
3. 경기 정보 오류 방지는 현재 프롬프트 지침에 의존한다. 출처와 날짜·상대·스코어를 대조하는 검증이 필요하다.
4. 웹 본문 조회는 사설 IP·리다이렉트·응답 크기 제한과 스크립트 제거를 보강해야 한다. 외부 텍스트를 시스템 명령으로 취급하지 않도록 분리해야 한다.
5. 모델 목록의 존재만으로 메모리 로드 상태를 단정하지 않도록 표시를 수정하고, 한국어 IME 조합 중 Enter 및 저장된 빈 모델 설정도 회귀 확인한다.

## 다음 작업 재개

Codex에서 상위 projects 폴더 대신 **local-web-agent 폴더 자체**를 프로젝트로 연다.
CLI를 사용하는 경우 프로젝트 루트에서 실행한다.

```powershell
codex
```

아래는 PowerShell 명령이 아니라 **Codex 대화창에 입력하는 스킬 호출**이다.

```text
$aidlc --status
$aidlc --resume
```

첫 입력 후 터미널에서 환경 점검을 다시 실행한다.

```powershell
bun .codex/tools/aidlc-utility.ts doctor
```

등록된 훅이 실패하면 진단 내용을 해결한 뒤 이어간다. 건강 상태를 통과시키기 위해
heartbeat나 사람 입력 영수증을 수동으로 위조하지 않는다.
재개 후 기존 코드 분석 → 프로젝트 관행 확인 → 요구사항 및 검증 계획 순으로 진행하며,
오늘 미해결 목록을 먼저 읽는다.
